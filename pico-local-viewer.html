本地查看方式

这个页面是单文件工具，可以直接用浏览器打开。由于浏览器安全限制，它不会自动扫描硬盘；你需要手动选择项目根目录或 `.pico` 目录。页面只读取你选择的文件，解析发生在当前浏览器标签页里。

推荐查看顺序：先看 Run 列表，再点进某个 Run 看 trace 时间线，最后去 Sessions 看长期 memory 和 checkpoint。
